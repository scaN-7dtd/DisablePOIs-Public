1. MOD INFORMATION

This mod disables zombie spawns inside POIs (Points of Interest), including regular sleepers and 
any other type of zombie spawn activated by the Trigger Block-Volume system.

You can also re-enable the regular zombie sleeper spawns.


----------------------------------------------------------------------------------------------------

1.2 Notes

- This mod will obviously break quests, etc.

- This mod will obviously break the POI door system, meaning that any locked door that relies on 
key racks, switches, or similar mechanisms will no longer be able to be opened.

- This mod also disables the flame emitted by the broken pipe, since the mod itself disables the 
valves, leaving no way to turn the flame off.


====================================================================================================

2. GENERAL INFORMATION

- A new savegame is NOT NEEDED.

- The mod was developed and tested in single-player on game version 3.2.0 (b10) on Windows 10.

- This mod improves performance by disabling zombie spawns, and the methods used to disable them 
have no performance impact.


----------------------------------------------------------------------------------------------------

2.1 REQUIREMENTS

- Easy AntiCheat disabled.

- Game version: Should work in any 3.X version.

- Dedicated Servers: Should NOT be compatible.

----------------------------------------------------------------------------------------------------

2.2 INSTALLATION

1) Make a backup of your game save file.

2) Unzip the downloaded file and put the folder "DisablePOIs" inside your "mods" folder.


====================================================================================================

3. MOD CONFIGURATION

Open "config.xml" inside the mods folder and change the line: disableSleeperSpawn="true"

true = disables regular sleepers spawns

false = regular sleepers spawn (default spawning)
