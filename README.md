# Disable POIs

This mod disables zombie spawns inside POIs (Points of Interest), including regular sleepers and any other type of zombie spawn activated by the Trigger Block-Volume system.

You can also re-enable the regular zombie sleeper spawns.

This mod also disables the flame emitted by the broken pipe, since the mod itself disables the valves, leaving no way to turn the flame off.

More information in the `README.txt` file.
